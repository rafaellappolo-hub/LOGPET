
# LOGPET Animal Rescue Website

This is a code bundle for LOGPET Animal Rescue Website. The original project is available at https://www.figma.com/design/3KLUWyh323ZGaQ41M7Jk4A/LOGPET-Animal-Rescue-Website.

## Rodando localmente

Use Node.js 24+ com Corepack habilitado.

```powershell
corepack.cmd pnpm install
corepack.cmd pnpm run dev
```

Depois abra a URL exibida pelo Vite, normalmente `http://localhost:5173/`.

Para gerar a build de producao:

```powershell
corepack.cmd pnpm run build
```
